# 준혁T의 과학 실험실

중학교 2학년 과학 수업용 한국어 시뮬레이션 모음입니다. 모든 실험은 사용자가 제공한 교과서·교사용 교과서·지도서 PDF와 교육과정 성취기준에 맞추어 만들고, 각 실험은 `예상하기 → 관찰하기 → 설명하기` 순서로 진행합니다.

| 단원 | 차시 | 실험 | 주소 | 성취기준 |
|---|---|---|---|---|
| VII. 전기와 자기 | 01 (교과서 236–237쪽) | 마찰 전기 | `/simulations/friction-electricity/` | [9과14-01] |
| VII. 전기와 자기 | 02 (교과서 238–241쪽) | 정전기 유도 | `/simulations/electrostatic-induction/` | [9과14-01] |

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev -- --port 5173
npm test
npm run build
```

브라우저 통합 테스트:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

## 배포 (Netlify)

- `netlify.toml`에 따라 Netlify가 `npm run build -- --base=/`로 빌드하고 `dist/`를 배포합니다(Node.js 24).
- Netlify에 연결된 GitHub 브랜치(보통 `main`)에 변경이 올라가면 Netlify가 자동으로 다시 배포합니다.
- 새 실험을 추가할 때는 `simulations/실험이름/index.html`을 만들고 `vite.config.js`의 빌드 입력, `netlify.toml`의 끝 슬래시 리다이렉트, 해당 단원 폴더의 카드 링크를 함께 추가합니다.
- `.github/workflows/pages.yml`의 GitHub Pages 배포도 남아 있습니다. 상대 자산 경로를 사용하므로 저장소 하위 경로(`https://epicwnsgur.github.io/science-simulations/`)에서도 동작합니다.

외부 API·계정·비밀키·서버 데이터 저장은 없습니다. 외부 글꼴 요청 없이 시스템 글꼴로 표시합니다. 학생이 쓴 예상·관찰·설명은 현재 페이지 메모리에만 있고 서버로 보내지 않습니다. PDF는 웹 배포물에 포함하지 않습니다.

## 정전기 유도 (VII-1 02차시)

교과서 인쇄 238–241쪽, 교사용 교과서 238–241쪽의 탐구 활동 유의점·오개념 해결, 지도서 인쇄 544–549쪽(2–3차시)의 지도상 유의점·보충 설명을 근거로 만들었습니다. `induction.js`(화면), `induction.css`, `src/induction-model.js`(전하 모형), `src/poe-flow.js`(내용을 설정으로 받는 학습 흐름)를 사용합니다.

### 활동

- **01 쇠숟가락 움직이기 (해 보기, 238쪽):** 추를 올린 쇠숟가락의 손잡이 끝에 대전되지 않은 빨대, 털가죽으로 문질러 (−)전하를 띤 빨대, 빨대와 문질러 (+)전하를 띤 장갑을 가까이 합니다. (−)빨대는 전자를 먼 쪽으로 밀어내고 (+)장갑은 전자를 가까운 쪽으로 끌어당겨, 두 경우 모두 가까운 쪽에 대전체와 다른 종류의 전하가 유도되어 숟가락이 추를 중심으로 대전체 쪽으로 돌아갑니다. 대전되지 않은 빨대에는 반응하지 않습니다.
- **02 검전기 관찰하기 (탐구, 240–241쪽):** 빨대·풍선(털가죽과 문지름, (−))과 장갑(빨대와 문지름, (+))을 고르고 문지르지 않음 / 2~3번 / 10번 이상 중 하나를 골라 금속판에 가까이 합니다. 금속판에는 대전체와 다른 종류, 금속박에는 같은 종류의 전하가 유도되어 두 금속박이 척력으로 벌어집니다. 많이 문지를수록, 가까울수록 더 많은 전자가 금속 막대를 따라 이동해 더 많이 벌어집니다.
- **관찰 조건:** (−)빨대와 (+)장갑으로 각각 숟가락 움직이기, 검전기에 2~3번과 10번 이상 문지른 물체 가까이 하기. 네 가지를 모두 해야 설명 단계로 넘어갑니다.
- **설명 단계:** 정전기 유도 과정, 대전체 종류와 관계없이 인력이 작용하는 까닭, 검전기 원리를 정리하고 스스로 평가 두 문항(241쪽)과 핵심 용어(정전기 유도, 검전기, 대전체, 전기력, 인력, 척력)를 제공합니다.

### 교육과정 범위와 모형

- 금속 안에서 **전자만** 이동하고 원자핵은 제자리에 있습니다(지도상 유의점: 정전기 유도를 (−)전하를 띤 전자의 이동으로 설명).
- 대전체는 금속에 **닿지 않습니다.** 끌기·버튼·키보드 모두 일정 거리 밖에서 멈추고, 숟가락도 닿기 전에 멈춥니다(지도상 유의점: 대전된 물체가 금속 물체에 닿는 상황은 다루지 않음). 접촉 대전, 손가락 접지로 검전기 전체를 대전시키기 같은 지도서 보충 설명은 넣지 않았습니다.
- 빨대·풍선·장갑 같은 부도체 안의 전하 재배치(유전 분극)는 다루지 않으므로 그리지 않습니다. 대전체에는 교과서 그림처럼 대전된 만큼 남는 전하만 표시합니다.
- 오개념(교사용 교과서 239쪽, 지도서 547쪽) 대응: 전자가 가장 많이 몰려도 가까운 쪽과 먼 쪽, 금속판과 금속박에 두 종류의 전하가 모두 남습니다. 설명 단계에서 "가까운 쪽에 (+)전하만 있는 것은 아니며 상대적으로 많아진 것"임을 짚습니다.
- 숟가락은 인력에 의한 돌림힘이 바닥 마찰보다 클 때만 돌고, 대전체를 멀리 해도 끌려온 자리에 남습니다. 전하 분포는 대전체가 멀어지면 원래대로 돌아갑니다.
- 입자 수, 이동 거리, 금속박 각도, 거리에 따른 반응은 보기 쉽게 나타낸 정성적 표현이며 측정값이나 정량 관계(쿨롱 법칙 등)를 뜻하지 않습니다.
- 풍선 그림은 마찰 전기 실험의 `public/images/balloon-fur.png`를 다시 사용합니다. 숟가락·검전기·빨대·장갑은 SVG로 직접 그렸습니다.

## 마찰 전기 (VII-1 01차시)

### 활동

- 화면 중앙 아래에 고정된 털 위에서 풍선을 마우스·터치로 잡아 움직이면 털에서 풍선으로 전자가 이동합니다. 키보드 방향키 및 ‘한 번 문지르기’ 버튼도 지원합니다.
- 원자핵은 물체에 묶인 채 작은 범위에서 반응하며, 물체 사이에서 이동한 만큼 털의 전자를 줄이고 풍선의 전자를 늘립니다. 대전 후에도 두 종류의 전하가 남습니다.
- 전기력 활동은 미리 대전한 풍선과 털(인력), 두 풍선(척력)을 별도 비교합니다. 화살표와 움직임은 힘의 방향만 나타냅니다.
- 여섯 핵심 용어, 확인 문제, 초기화, 전하 표시 전환, 학습에 필요한 안내를 제공합니다.

### 근거 및 범위

사용자가 제공한 교과서 PDF의 인쇄 236–237쪽, 교사용 교과서 237쪽 오개념 지도, 지도서 인쇄 540–543쪽, 과학과 교육과정 인쇄 52–53쪽의 [9과14-01] 중 마찰 전기 내용을 참고했습니다. 삽화는 웹앱을 위해 별도 제작했습니다.

원자핵의 (+)전하 및 전자의 (−)전하를 단순화한 모형입니다. 표시 수와 이동 거리는 측정값이 아니며, 마찰 횟수와 실제 전하량 사이의 정량 관계를 뜻하지 않습니다. 전기력 활동의 대전 상태는 마찰 활동과 독립된 준비 상태입니다. 중성 물체에 대한 분극, 정전기 유도, 방전, 대전열, 쿨롱 법칙은 구현 범위 밖입니다. 교사용 심화 내용을 학생 활동에 포함하지 않습니다.

### 이미지와 마찰 후 움직임

`public/images/balloon-fur.png`는 이 앱을 위해 생성한 사실적 풍선·털 이미지입니다. 교과서 그림을 복제하거나 실물 사진이라고 제시하지 않습니다. 투명한 이미지 한 장을 SVG 뷰포트로 나누어 표시합니다.

마찰 후 풍선을 털 가까이에 들어 올리면 밑부분은 고정된 채 가까운 털끝 패치만 뿌리를 기준으로 휘고 늘어납니다. 멀리 가져가면 부드럽게 펴집니다. 원본 이미지에 마스크를 씌운 국소 변형으로, 털 전체를 평행이동하지 않습니다. 중성 상태에는 이 반응이 없으며 들어 올리기는 전자를 추가로 이동시키지 않습니다.

전하 기호는 이미지의 불투명한 영역 안쪽에 배치하고, 이동 중에도 각 물체 내부로 클리핑합니다. 처음에는 양·음전하를 섞어 나타내며 전기력에 대한 제한된 내부 반응을 매 프레임 갱신합니다. 풍선과 털은 절연체이므로 마찰로 생긴 전하 차이를 도체처럼 전체에 균일하게 퍼뜨리지 않습니다. 접촉 부근의 전자가 이동하고, 풍선에 추가된 전자는 문지른 쪽에 남는 간단한 모형입니다. 원자 배열이나 기호의 개수·간격을 실제 크기나 밀도로 해석하지 않습니다.

전자 이동은 실제로 겹치는 내부 접촉점을 경유해 털에서 풍선으로 이어집니다. 공중을 통과하는 큰 곡선 궤적은 없습니다. 이동 중에는 도착 위치의 기호를 중복 표시하지 않아 전체 전하 표시 수가 보존됩니다. 접촉이 끊기면 이동이 끝난 상태로 정리합니다.

전기력 관찰은 감쇠된 움직임으로 시작·정지하고 반복 실행할 수 있습니다. 인력에서는 지지된 털의 밑부분이 고정되고 풍선과 가까운 털끝이 반응하며, 척력에서는 두 풍선이 서로 멀어집니다. 변형량·마찰량·전기력·중력의 정량 역학 계산은 하지 않으며, 화면은 힘의 방향을 관찰하는 정성적 모형입니다. 모드 전환·초기화 시 진행 중인 모션을 취소하고, 동작 줄이기 설정도 지원합니다.

학생 화면의 영문 장식 문구와 교사용 자료·모형 안내 창은 제거했습니다. 출처와 교사용 설명은 이 문서에만 남깁니다. 전하 표시와 수 비교는 ‘전하 보기’를 켰을 때만 표시합니다.


### 전하의 실시간 반응과 표시

양전하 기호는 반지름 8의 빨간색(#e84444), 음전하는 반지름 5.2의 파란색(#2787d9)이며 두 기호 모두 흰색입니다. 교과서식 구분을 위한 표시로, 원자핵과 전자의 실제 크기 비율이 아닙니다.

`stepBoundCharge`는 다른 물체의 순전하로부터 받는 전기력 방향, 국소 복원력, 감쇠를 계산하는 고전적인 결합 전하 근사 모형입니다. 상대 물체의 위치·전하가 바뀌면 입자 표시가 계속 반응합니다. 양전하의 반응은 음전하보다 작으며, 원자핵이나 전자가 절연체 안을 자유롭게 돌아다니지는 않습니다. 마찰로 옮겨 간 전자도 문지른 부근에 묶입니다. 평형 상태에서는 멈추며, 임의의 지속 진동이나 전자의 고전적 원궤도를 추가하지 않습니다.

좌표, 질량에 해당하는 반응 차이, 힘의 크기, 복원 계수, 시간은 시각화를 위한 무차원 값입니다. 다른 물체는 순전하의 유한 크기 근사로 취급하며, 분자·양자 궤적이나 정확한 유전 분극을 계산하지 않습니다. 중학교 마찰 전기 활동에 정량 법칙이나 새 용어를 추가하지 않으며, 이 근사 반응은 별도의 검증된 물성 시뮬레이터가 아닙니다.

반응 범위와 이미지 윤곽을 함께 제한하여 큰 양전하 표시도 물체 밖으로 나가지 않습니다. 초기화하면 속도와 내부 반응 상태를 지우고 중성 상태로 복귀합니다. 전하를 숨겼다가 다시 표시해도 반응 상태와 전체 전하 수를 유지합니다.


### 고정된 털과 접촉 위치별 전하 배치

마찰 활동과 인력 관찰에서 털의 밑부분은 실험 공간의 중앙 아래에 고정됩니다. 털에는 드래그·방향키 이벤트나 탭 순서를 부여하지 않으며, 풍선만 학생이 직접 조작합니다. 척력 활동에서는 털 대신 두 번째 풍선을 표시하고 두 풍선의 움직임을 관찰합니다.

추가 전자는 접촉 순간의 풍선 내부 좌표 가까이에 기록합니다. 기존 입자를 피하고 이미지 안쪽에 들어가는 자리를 선택하며, 이후 풍선을 옮겨도 이미 기록한 마찰 위치를 다시 배치하지 않습니다. 왼쪽이나 오른쪽의 고정된 줄을 만들지 않습니다. 버튼 실험은 털의 여러 위치를 번갈아 문지릅니다. 이 과정은 절연체의 마찰 부위에 전하가 남는 모형이며, 도체처럼 전하를 전체에 균일하게 퍼뜨리지 않습니다.

입자 기호는 흰색 SVG 선으로 원 지름의 약 80% 이상을 채웁니다. SVG 이미지의 숨겨진 영역까지 포함하던 브라우저 포커스 사각형은 제거했습니다. 마우스·터치로 클릭할 때 테두리가 생기지 않고, 키보드로 풍선을 선택할 때만 풍선 크기의 타원형 표시를 제공합니다.

## 메인 페이지와 실험 폴더

`/`는 준혁T의 과학 실험실 메인 화면입니다. ‘중학교 2학년 과학’ 폴더를 열면 `/grades/middle-school-2/`에서 8개의 단원 폴더를 볼 수 있습니다. `unit-7/`(VII. 전기와 자기)에 마찰 전기, 정전기 유도와 준비 중인 실험 하나가 있습니다. 카드 탭은 모두 ‘실험’으로 표시합니다. 마찰 전기는 `/simulations/friction-electricity/`로 연결되며, 상단의 ‘← 실험 목록’으로 7단원 폴더에 돌아올 수 있습니다.

`index.html`과 `home.css`가 메인 화면을 담당하며, 기존 `main.js`와 `style.css`는 실험 화면에서만 사용합니다. Vite 다중 페이지 빌드로 각 주소의 HTML을 실제 생성하므로 GitHub Pages 하위 경로와 Netlify에서 직접 접속·새로고침이 가능합니다. 새 실험은 `simulations/실험이름/index.html`을 만들고 `vite.config.js`의 빌드 입력 및 해당 단원 폴더 링크에 추가합니다. 아직 준비되지 않은 폴더에는 링크를 넣지 않습니다.

### 마찰 전기의 POE 학습 흐름

마찰 전기는 `예상하기 → 관찰하기 → 설명하기` 순서로 진행합니다. `src/poe.js`와 `poe.css`가 학습 화면을 담당하고, 기존 물리 모형과 마우스·터치·키보드 조작은 그대로 사용합니다.

- 예상: 움직임을 선택하고 까닭을 적습니다. 실험·전하 이동·정답 해설은 아직 보이지 않습니다. 모른다는 예상도 허용하고 정오를 채점하지 않습니다. 처음 예상은 관찰 후 바꿔 쓰지 않도록 보존합니다.
- 관찰: 풍선을 문지르고 가까이 들어 올려 털끝을 관찰한 뒤 결과를 기록합니다. 전하 표시는 학생이 선택해 켤 수 있습니다. 이 단계의 안내는 관찰 질문이며, 핵심 개념 해설과 확인 문제는 설명 단계로 옮깁니다.
- 설명: 처음 예상과 실제 관찰을 비교해 자기 설명을 작성한 다음 전자 이동, 대전, 대전체, 전기력, 인력·척력을 정리합니다. 개념 확인 뒤 자기 설명을 보완하거나 다시 실험할 수 있습니다.

단계 이동과 ‘실험 초기화’는 작성한 글을 보존하고, ‘기록 지우고 처음부터’는 글과 실험을 모두 초기화합니다. 기록은 현재 페이지 메모리에만 유지되며 서버로 전송하지 않습니다. 새로고침 또는 다른 페이지로 이동하면 사라집니다.
