## 공통 구조

- `src/lab-shell.js`, `lab.css`: 실험 페이지 틀(활동 탭, 어두운 실험 무대, 관찰 기록, 스스로 평가, 핵심 개념)과 시각 효과(빛 번짐, 불꽃, 알림, 경로를 따라 흐르는 전자·물 알갱이).
- `theme-electric.css`: 전기와 자기 단원 공통 디자인(어두운 회로 기판 배경, 전류는 하늘색·전압은 노란색·자석은 빨강/파랑, 빛나는 버튼과 무대). 모든 실험이 마지막에 불러옵니다. 단원 페이지는 `unit-electric.css`를 씁니다.
- `src/poe-flow.js`: 예상하기 → 관찰하기 → 설명하기 흐름. 실험마다 관찰 체크리스트를 모두 마쳐야 설명 단계로 넘어갑니다.
- `src/*-model.js`: 실험별 모형과 `node --test`로 확인하는 단위 테스트.
- `vite.config.js`는 `simulations/` 아래 폴더를 자동으로 빌드에 넣습니다. 새 실험은 폴더를 만들고 `netlify.toml` 리다이렉트와 단원 카드만 추가하면 됩니다.

## 3~8번 실험의 근거와 범위

- **전류와 전압:** 마찰 전기로 네온전구를 순간적으로 켜고, 다시 대면 켜지지 않음을 확인합니다. 전지 회로에서 전자는 (−)극→(+)극, 전류는 (+)극→(−)극으로 표시하고, 전구로 들어간 전자와 나온 전자 수가 같음을 셉니다. 수로 모형의 한계를 화면에 안내합니다(지도서 555쪽).
- **전압, 전류, 저항:** 지도서 561쪽 결과(긴 니크롬선 1 V당 50 mA, 짧은 니크롬선 100 mA)를 사용해 표와 그래프를 그립니다. 스위치를 오래 닫으면 니크롬선이 달아오르며 경고합니다. 도체·부도체 분류 활동을 포함합니다.
- **저항의 연결:** 같은 전구 두 개만 다루고 계산·혼합 연결은 다루지 않습니다(지도서 566쪽). 밝기를 회로 카드처럼 1~3칸으로 칠합니다.
- **전류가 만든 자기장:** 나침반 8개와 움직일 수 있는 나침반으로 관찰합니다. 바늘은 지구 자기장과 합쳐진 방향을 가리킵니다. 스위치는 누르는 동안만 전류가 흐릅니다. ‘자기력선’ 용어는 쓰지 않습니다(지도서 586쪽).
- **전기 그네:** 처음 상태에서 바깥쪽(㉮), 전류나 극 중 하나를 바꾸면 안쪽(㉯)으로 움직입니다(지도서 592쪽). 전압이 클수록 많이 움직입니다.
- **전동기:** 그림 Ⅶ-16을 앞에서 본 모습으로 코일 두 변의 힘을 보여 주고, 간이 전동기(264쪽)에서 에나멜을 반만 벗긴 경우와 모두 벗긴 경우를 비교합니다.
- 모든 수치·속도·각도는 정성적 비교를 위한 화면 표현입니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev -- --port 5173
npm test
npm run build
```

브라우저 통합 테스트:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

## 배포 (Netlify)

- `netlify.toml`에 따라 Netlify가 `npm run build -- --base=/`로 빌드하고 `dist/`를 배포합니다(Node.js 24).
- Netlify에 연결된 GitHub 브랜치(보통 `main`)에 변경이 올라가면 Netlify가 자동으로 다시 배포합니다.
- 새 실험을 추가할 때는 `simulations/실험이름/index.html`을 만들고 `vite.config.js`의 빌드 입력, `netlify.toml`의 끝 슬래시 리다이렉트, 해당 단원 폴더의 카드 링크를 함께 추가합니다.
- `.github/workflows/pages.yml`의 GitHub Pages 배포도 남아 있습니다. 상대 자산 경로를 사용하므로 저장소 하위 경로(`https://epicwnsgur.github.io/science-simulations/`)에서도 동작합니다.

외부 API·계정·비밀키·서버 데이터 저장은 없습니다. 외부 글꼴 요청 없이 시스템 글꼴로 표시합니다. 학생이 쓴 예상·관찰·설명은 현재 페이지 메모리에만 있고 서버로 보내지 않습니다. PDF는 웹 배포물에 포함하지 않습니다.

## 정전기 유도 (VII-1 02차시)

교과서 인쇄 238–241쪽, 교사용 교과서 238–241쪽의 탐구 활동 유의점·오개념 해결, 지도서 인쇄 544–549쪽(2–3차시)의 지도상 유의점·보충 설명을 근거로 만들었습니다. `induction.js`(화면), `induction.css`, `src/induction-model.js`(전하 모형), `src/poe-flow.js`(내용을 설정으로 받는 학습 흐름)를 사용합니다.

### 활동

- **01 쇠숟가락 움직이기 (해 보기, 238쪽):** 추를 올린 쇠숟가락의 손잡이 끝에 대전되지 않은 빨대, 털가죽으로 문질러 (−)전하를 띤 빨대, 빨대와 문질러 (+)전하를 띤 장갑을 가까이 합니다. (−)빨대는 전자를 먼 쪽으로 밀어내고 (+)장갑은 전자를 가까운 쪽으로 끌어당겨, 두 경우 모두 가까운 쪽에 대전체와 다른 종류의 전하가 유도되어 숟가락이 추를 중심으로 대전체 쪽으로 돌아갑니다. 대전되지 않은 빨대에는 반응하지 않습니다.
- **02 검전기 관찰하기 (탐구, 240–241쪽):** 빨대·풍선(털가죽과 문지름, (−))과 장갑(빨대와 문지름, (+))을 고르고 문지르지 않음 / 2~3번 / 10번 이상 중 하나를 골라 금속판에 가까이 합니다. 금속판에는 대전체와 다른 종류, 금속박에는 같은 종류의 전하가 유도되어 두 금속박이 척력으로 벌어집니다. 많이 문지를수록, 가까울수록 더 많은 전자가 금속 막대를 따라 이동해 더 많이 벌어집니다.
- **관찰 조건:** (−)빨대와 (+)장갑으로 각각 숟가락 움직이기, 검전기에 2~3번과 10번 이상 문지른 물체 가까이 하기. 네 가지를 모두 해야 설명 단계로 넘어갑니다.
- **설명 단계:** 정전기 유도 과정, 대전체 종류와 관계없이 인력이 작용하는 까닭, 검전기 원리를 정리하고 스스로 평가 두 문항(241쪽)과 핵심 용어(정전기 유도, 검전기, 대전체, 전기력, 인력, 척력)를 제공합니다.

### 교육과정 범위와 모형

- 금속 안에서 **전자만** 이동하고 원자핵은 제자리에 있습니다(지도상 유의점: 정전기 유도를 (−)전하를 띤 전자의 이동으로 설명).
- 대전체는 금속에 **닿지 않습니다.** 끌기·버튼·키보드 모두 일정 거리 밖에서 멈추고, 숟가락도 닿기 전에 멈춥니다(지도상 유의점: 대전된 물체가 금속 물체에 닿는 상황은 다루지 않음). 접촉 대전, 손가락 접지로 검전기 전체를 대전시키기 같은 지도서 보충 설명은 넣지 않았습니다.
- 빨대·풍선·장갑 같은 부도체 안의 전하 재배치(유전 분극)는 다루지 않으므로 그리지 않습니다. 대전체에는 교과서 그림처럼 대전된 만큼 남는 전하만 표시합니다.
- 오개념(교사용 교과서 239쪽, 지도서 547쪽) 대응: 전자가 가장 많이 몰려도 가까운 쪽과 먼 쪽, 금속판과 금속박에 두 종류의 전하가 모두 남습니다. 설명 단계에서 "가까운 쪽에 (+)전하만 있는 것은 아니며 상대적으로 많아진 것"임을 짚습니다.
- 숟가락은 인력에 의한 돌림힘이 바닥 마찰보다 클 때만 돌고, 대전체를 멀리 해도 끌려온 자리에 남습니다. 전하 분포는 대전체가 멀어지면 원래대로 돌아갑니다.
- 입자 수, 이동 거리, 금속박 각도, 거리에 따른 반응은 보기 쉽게 나타낸 정성적 표현이며 측정값이나 정량 관계(쿨롱 법칙 등)를 뜻하지 않습니다.
- 풍선 그림은 마찰 전기 실험의 `public/images/balloon-fur.png`를 다시 사용합니다. 숟가락·검전기·빨대·장갑은 SVG로 직접 그렸습니다.

## 마찰 전기 (VII-1 01차시)

### 근거 및 범위

사용자가 제공한 교과서 PDF의 인쇄 236–237쪽, 교사용 교과서 237쪽 오개념 지도, 지도서 인쇄 540–543쪽, 과학과 교육과정 인쇄 52–53쪽의 [9과14-01] 중 마찰 전기 내용을 참고했습니다. 삽화는 웹앱을 위해 별도 제작했습니다.

원자핵의 (+)전하 및 전자의 (−)전하를 단순화한 모형입니다. 표시 수와 이동 거리는 측정값이 아니며, 마찰 횟수와 실제 전하량 사이의 정량 관계를 뜻하지 않습니다. 전기력 활동의 대전 상태는 마찰 활동과 독립된 준비 상태입니다. 중성 물체에 대한 분극, 정전기 유도, 방전, 대전열, 쿨롱 법칙은 구현 범위 밖입니다. 교사용 심화 내용을 학생 활동에 포함하지 않습니다. 해 보기의 숟가락 활동은 238쪽처럼 장갑과 문지른 숟가락이 (−), 장갑이 (+)를 띠는 것으로 나타냈습니다.

### 활동

- **풍선과 털 문지르기:** 풍선을 끌거나 버튼으로 털에 문지르면 털에서 풍선으로 전자가 빛나며 이동합니다. 문지른 풍선을 털 가까이 들어 올리면 털끝이 풍선 쪽으로 휘고, 밑부분은 제자리에 있습니다.
- **숟가락으로 힘 관찰하기 (해 보기 236쪽):** 장갑으로 문지른 숟가락 ㉯를 가까이 하면 숟가락 ㉮가 밀려나고(척력), 장갑을 가까이 하면 끌려옵니다(인력). 숟가락 ㉮는 닿기 전에 멈춥니다.
- 풍선·털 그림은 `public/images/balloon-fur.png`를 사용합니다.

## 메인 페이지와 실험 폴더

`/`는 준혁T의 과학 실험실 메인 화면입니다. ‘중학교 2학년 과학’ 폴더를 열면 `/grades/middle-school-2/`에서 8개의 단원 폴더를 볼 수 있습니다. `unit-7/`(VII. 전기와 자기)에 8개의 실험이 있습니다. 카드 탭은 모두 ‘실험’으로 표시합니다. 마찰 전기는 `/simulations/friction-electricity/`로 연결되며, 상단의 ‘← 실험 목록’으로 7단원 폴더에 돌아올 수 있습니다.

`index.html`과 `home.css`가 메인 화면을 담당하며, `style.css`·`poe.css`·`lab.css`는 실험 화면에서 사용합니다. Vite 다중 페이지 빌드로 각 주소의 HTML을 실제 생성하므로 GitHub Pages 하위 경로와 Netlify에서 직접 접속·새로고침이 가능합니다. 학생이 쓴 예상·관찰·설명은 페이지 메모리에만 있고 새로고침하면 사라집니다.
