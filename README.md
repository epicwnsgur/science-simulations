# 작은 과학실 — 마찰 전기

중학교 2학년 과학 VII. 전기와 자기, 교과서 236–237쪽에 맞춘 한국어 웹앱입니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev -- --port 5173
npm test
npm run build
```

브라우저 통합 테스트:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

## 활동

- 풍선 또는 털을 마우스·터치로 잡아 접촉 범위에서 움직이면 털에서 풍선으로 전자가 이동합니다. 키보드 방향키 및 ‘한 번 문지르기’ 버튼도 지원합니다.
- 원자핵의 양전하는 그대로 두고, 이동한 만큼 털의 전자를 줄이고 풍선의 전자를 늘립니다. 대전 후에도 두 종류의 전하가 남습니다.
- 전기력 활동은 미리 대전한 풍선과 털(인력), 두 풍선(척력)을 별도 비교합니다. 화살표와 움직임은 힘의 방향만 나타냅니다.
- 여섯 핵심 용어, 확인 문제, 초기화, 전하 표시 전환, 학습에 필요한 안내를 제공합니다.

## 근거 및 범위

사용자가 제공한 교과서 PDF의 인쇄 236–237쪽, 교사용 교과서 237쪽 오개념 지도, 지도서 인쇄 540–543쪽, 과학과 교육과정 인쇄 52–53쪽의 [9과14-01] 중 마찰 전기 내용을 참고했습니다. 삽화는 웹앱을 위해 별도 제작했으며 PDF를 웹 배포물에 포함하지 않습니다.

원자핵의 (+)전하 및 전자의 (−)전하를 단순화한 모형입니다. 표시 수와 이동 거리는 측정값이 아니며, 마찰 횟수와 실제 전하량 사이의 정량 관계를 뜻하지 않습니다. 전기력 활동의 대전 상태는 마찰 활동과 독립된 준비 상태입니다. 중성 물체에 대한 분극, 정전기 유도, 방전, 대전열, 쿨롱 법칙은 구현 범위 밖입니다. 교사용 심화 내용을 학생 활동에 포함하지 않습니다.

외부 API·계정·비밀키·서버 데이터 저장은 없습니다. 외부 글꼴 요청 없이 시스템 글꼴로 표시합니다. `dist/`를 정적 호스팅할 수 있습니다.

## GitHub Pages 배포

- 소스: `main` 브랜치
- GitHub 저장소 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 설정합니다.
- **Actions → Deploy GitHub Pages → Run workflow → main**으로 첫 배포를 실행합니다.
- 성공 후 주소: `https://epicwnsgur.github.io/science-simulations/`
- 이후 `main`에 변경을 올리면 `.github/workflows/pages.yml`이 테스트·빌드 후 자동 배포합니다.
- 상대 자산 경로를 사용하므로 GitHub Pages의 저장소 하위 경로에서도 동작합니다.


## 이미지와 마찰 후 움직임

`public/images/balloon-fur.png`는 이 앱을 위해 생성한 사실적 풍선·털 이미지입니다. 교과서 그림을 복제하거나 실물 사진이라고 제시하지 않습니다. 투명한 이미지 한 장을 SVG 뷰포트로 나누어 표시합니다.

마찰 후 풍선을 털 가까이에 들어 올리면 밑부분은 고정된 채 가까운 털끝 패치만 뿌리를 기준으로 휘고 늘어납니다. 멀리 가져가면 부드럽게 펴집니다. 원본 이미지에 마스크를 씌운 국소 변형으로, 털 전체를 평행이동하지 않습니다. 중성 상태에는 이 반응이 없으며 들어 올리기는 전자를 추가로 이동시키지 않습니다.

전하 기호는 이미지의 불투명한 영역 안쪽에 배치하고, 이동 중에도 각 물체 내부로 클리핑합니다. 처음에는 양·음전하를 섞어 나타내며 양전하 위치는 고정합니다. 풍선과 털은 절연체이므로 마찰로 생긴 전하 차이를 도체처럼 전체에 균일하게 퍼뜨리지 않습니다. 접촉 부근의 전자가 이동하고, 풍선에 추가된 전자는 문지른 쪽에 남는 간단한 모형입니다. 원자 배열이나 기호의 개수·간격을 실제 크기나 밀도로 해석하지 않습니다.

전자 이동은 실제로 겹치는 내부 접촉점을 경유해 털에서 풍선으로 이어집니다. 공중을 통과하는 큰 곡선 궤적은 없습니다. 이동 중에는 도착 위치의 기호를 중복 표시하지 않아 전체 전하 표시 수가 보존됩니다. 접촉이 끊기면 이동이 끝난 상태로 정리합니다.

전기력 관찰은 감쇠된 움직임으로 시작·정지하고 반복 실행할 수 있습니다. 인력에서는 지지된 털의 밑부분이 고정되고 풍선과 가까운 털끝이 반응하며, 척력에서는 두 풍선이 서로 멀어집니다. 변형량·마찰량·전기력·중력의 정량 역학 계산은 하지 않으며, 화면은 힘의 방향을 관찰하는 정성적 모형입니다. 모드 전환·초기화 시 진행 중인 모션을 취소하고, 동작 줄이기 설정도 지원합니다.

학생 화면의 영문 장식 문구와 교사용 자료·모형 안내 창은 제거했습니다. 출처와 교사용 설명은 이 문서에만 남깁니다. 전하 표시와 수 비교는 ‘전하 보기’를 켰을 때만 표시합니다.
