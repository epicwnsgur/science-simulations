# 작은 과학실 — 마찰 전기

중학교 2학년 과학 VII. 전기와 자기, 교과서 236–237쪽에 맞춘 한국어 웹앱입니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev -- --port 5173
npm test
npm run build
```

브라우저 통합 테스트:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

## 활동

- 화면 중앙 아래에 고정된 털 위에서 풍선을 마우스·터치로 잡아 움직이면 털에서 풍선으로 전자가 이동합니다. 키보드 방향키 및 ‘한 번 문지르기’ 버튼도 지원합니다.
- 원자핵은 물체에 묶인 채 작은 범위에서 반응하며, 물체 사이에서 이동한 만큼 털의 전자를 줄이고 풍선의 전자를 늘립니다. 대전 후에도 두 종류의 전하가 남습니다.
- 전기력 활동은 미리 대전한 풍선과 털(인력), 두 풍선(척력)을 별도 비교합니다. 화살표와 움직임은 힘의 방향만 나타냅니다.
- 여섯 핵심 용어, 확인 문제, 초기화, 전하 표시 전환, 학습에 필요한 안내를 제공합니다.

## 근거 및 범위

사용자가 제공한 교과서 PDF의 인쇄 236–237쪽, 교사용 교과서 237쪽 오개념 지도, 지도서 인쇄 540–543쪽, 과학과 교육과정 인쇄 52–53쪽의 [9과14-01] 중 마찰 전기 내용을 참고했습니다. 삽화는 웹앱을 위해 별도 제작했으며 PDF를 웹 배포물에 포함하지 않습니다.

원자핵의 (+)전하 및 전자의 (−)전하를 단순화한 모형입니다. 표시 수와 이동 거리는 측정값이 아니며, 마찰 횟수와 실제 전하량 사이의 정량 관계를 뜻하지 않습니다. 전기력 활동의 대전 상태는 마찰 활동과 독립된 준비 상태입니다. 중성 물체에 대한 분극, 정전기 유도, 방전, 대전열, 쿨롱 법칙은 구현 범위 밖입니다. 교사용 심화 내용을 학생 활동에 포함하지 않습니다.

외부 API·계정·비밀키·서버 데이터 저장은 없습니다. 외부 글꼴 요청 없이 시스템 글꼴로 표시합니다. `dist/`를 정적 호스팅할 수 있습니다.

## GitHub Pages 배포

- 소스: `main` 브랜치
- GitHub 저장소 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 설정합니다.
- **Actions → Deploy GitHub Pages → Run workflow → main**으로 첫 배포를 실행합니다.
- 성공 후 주소: `https://epicwnsgur.github.io/science-simulations/`
- 이후 `main`에 변경을 올리면 `.github/workflows/pages.yml`이 테스트·빌드 후 자동 배포합니다.
- 상대 자산 경로를 사용하므로 GitHub Pages의 저장소 하위 경로에서도 동작합니다.


## 이미지와 마찰 후 움직임

`public/images/balloon-fur.png`는 이 앱을 위해 생성한 사실적 풍선·털 이미지입니다. 교과서 그림을 복제하거나 실물 사진이라고 제시하지 않습니다. 투명한 이미지 한 장을 SVG 뷰포트로 나누어 표시합니다.

마찰 후 풍선을 털 가까이에 들어 올리면 밑부분은 고정된 채 가까운 털끝 패치만 뿌리를 기준으로 휘고 늘어납니다. 멀리 가져가면 부드럽게 펴집니다. 원본 이미지에 마스크를 씌운 국소 변형으로, 털 전체를 평행이동하지 않습니다. 중성 상태에는 이 반응이 없으며 들어 올리기는 전자를 추가로 이동시키지 않습니다.

전하 기호는 이미지의 불투명한 영역 안쪽에 배치하고, 이동 중에도 각 물체 내부로 클리핑합니다. 처음에는 양·음전하를 섞어 나타내며 전기력에 대한 제한된 내부 반응을 매 프레임 갱신합니다. 풍선과 털은 절연체이므로 마찰로 생긴 전하 차이를 도체처럼 전체에 균일하게 퍼뜨리지 않습니다. 접촉 부근의 전자가 이동하고, 풍선에 추가된 전자는 문지른 쪽에 남는 간단한 모형입니다. 원자 배열이나 기호의 개수·간격을 실제 크기나 밀도로 해석하지 않습니다.

전자 이동은 실제로 겹치는 내부 접촉점을 경유해 털에서 풍선으로 이어집니다. 공중을 통과하는 큰 곡선 궤적은 없습니다. 이동 중에는 도착 위치의 기호를 중복 표시하지 않아 전체 전하 표시 수가 보존됩니다. 접촉이 끊기면 이동이 끝난 상태로 정리합니다.

전기력 관찰은 감쇠된 움직임으로 시작·정지하고 반복 실행할 수 있습니다. 인력에서는 지지된 털의 밑부분이 고정되고 풍선과 가까운 털끝이 반응하며, 척력에서는 두 풍선이 서로 멀어집니다. 변형량·마찰량·전기력·중력의 정량 역학 계산은 하지 않으며, 화면은 힘의 방향을 관찰하는 정성적 모형입니다. 모드 전환·초기화 시 진행 중인 모션을 취소하고, 동작 줄이기 설정도 지원합니다.

학생 화면의 영문 장식 문구와 교사용 자료·모형 안내 창은 제거했습니다. 출처와 교사용 설명은 이 문서에만 남깁니다. 전하 표시와 수 비교는 ‘전하 보기’를 켰을 때만 표시합니다.


## 전하의 실시간 반응과 표시

양전하 기호는 반지름 8의 빨간색(#e84444), 음전하는 반지름 5.2의 파란색(#2787d9)이며 두 기호 모두 흰색입니다. 교과서식 구분을 위한 표시로, 원자핵과 전자의 실제 크기 비율이 아닙니다.

`stepBoundCharge`는 다른 물체의 순전하로부터 받는 전기력 방향, 국소 복원력, 감쇠를 계산하는 고전적인 결합 전하 근사 모형입니다. 상대 물체의 위치·전하가 바뀌면 입자 표시가 계속 반응합니다. 양전하의 반응은 음전하보다 작으며, 원자핵이나 전자가 절연체 안을 자유롭게 돌아다니지는 않습니다. 마찰로 옮겨 간 전자도 문지른 부근에 묶입니다. 평형 상태에서는 멈추며, 임의의 지속 진동이나 전자의 고전적 원궤도를 추가하지 않습니다.

좌표, 질량에 해당하는 반응 차이, 힘의 크기, 복원 계수, 시간은 시각화를 위한 무차원 값입니다. 다른 물체는 순전하의 유한 크기 근사로 취급하며, 분자·양자 궤적이나 정확한 유전 분극을 계산하지 않습니다. 중학교 마찰 전기 활동에 정량 법칙이나 새 용어를 추가하지 않으며, 이 근사 반응은 별도의 검증된 물성 시뮬레이터가 아닙니다.

반응 범위와 이미지 윤곽을 함께 제한하여 큰 양전하 표시도 물체 밖으로 나가지 않습니다. 초기화하면 속도와 내부 반응 상태를 지우고 중성 상태로 복귀합니다. 전하를 숨겼다가 다시 표시해도 반응 상태와 전체 전하 수를 유지합니다.


## 고정된 털과 접촉 위치별 전하 배치

마찰 활동과 인력 관찰에서 털의 밑부분은 실험 공간의 중앙 아래에 고정됩니다. 털에는 드래그·방향키 이벤트나 탭 순서를 부여하지 않으며, 풍선만 학생이 직접 조작합니다. 척력 활동에서는 털 대신 두 번째 풍선을 표시하고 두 풍선의 움직임을 관찰합니다.

추가 전자는 접촉 순간의 풍선 내부 좌표 가까이에 기록합니다. 기존 입자를 피하고 이미지 안쪽에 들어가는 자리를 선택하며, 이후 풍선을 옮겨도 이미 기록한 마찰 위치를 다시 배치하지 않습니다. 왼쪽이나 오른쪽의 고정된 줄을 만들지 않습니다. 버튼 실험은 털의 여러 위치를 번갈아 문지릅니다. 이 과정은 절연체의 마찰 부위에 전하가 남는 모형이며, 도체처럼 전하를 전체에 균일하게 퍼뜨리지 않습니다.

입자 기호는 흰색 SVG 선으로 원 지름의 약 80% 이상을 채웁니다. SVG 이미지의 숨겨진 영역까지 포함하던 브라우저 포커스 사각형은 제거했습니다. 마우스·터치로 클릭할 때 테두리가 생기지 않고, 키보드로 풍선을 선택할 때만 풍선 크기의 타원형 표시를 제공합니다.

## 메인 페이지와 실험 폴더

`/`는 준혁T의 과학 실험실 메인 화면입니다. ‘중학교 2학년 과학’ 폴더를 열면 `/grades/middle-school-2/`에서 8개의 단원 폴더를 볼 수 있습니다. `unit-7/`(VII. 전기와 자기)에 마찰 전기와 준비 중인 실험 두 개가 있습니다. 카드 탭은 모두 ‘실험’으로 표시합니다. 마찰 전기는 `/simulations/friction-electricity/`로 연결되며, 상단의 ‘← 실험 목록’으로 7단원 폴더에 돌아올 수 있습니다.

`index.html`과 `home.css`가 메인 화면을 담당하며, 기존 `main.js`와 `style.css`는 실험 화면에서만 사용합니다. Vite 다중 페이지 빌드로 각 주소의 HTML을 실제 생성하므로 GitHub Pages 하위 경로와 Netlify에서 직접 접속·새로고침이 가능합니다. 새 실험은 `simulations/실험이름/index.html`을 만들고 `vite.config.js`의 빌드 입력 및 해당 단원 폴더 링크에 추가합니다. 아직 준비되지 않은 폴더에는 링크를 넣지 않습니다.
